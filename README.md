# My Learning Journey

A growing collection of interactive courses, generated as a static Docusaurus
site and deployed to GitHub Pages.

## Development

Requirements: Node.js 20 or newer and pnpm 10.26.0. With asdf installed, the
versions in `.tool-versions` are selected automatically.

```bash
pnpm install
pnpm serve
```

`pnpm serve` starts the development server with hot reload and does not require
a production build.

Create a production build in `build/`:

```bash
pnpm typecheck
pnpm build
pnpm preview
```

`pnpm preview` serves the generated `build/` directory exactly as it will be
deployed.

## Add a course

1. Create `docs/courses/<course-slug>/intro.md`.
2. Add `_category_.json` in that directory with its label, position, and intro
   document ID.
3. Organize lessons into Markdown or MDX files and subdirectories.
4. Add the course to the catalog in `docs/index.mdx`.

Navigation is autogenerated from `docs/`, so a new course does not require a
sidebar code change. Shared interactive React components belong in
`src/components/`.

## GitHub Pages

The workflow in `.github/workflows/deploy-pages.yml` installs dependencies with
pnpm, runs Docusaurus, and deploys the generated `build/` directory. In the
repository's **Settings → Pages**, set the source to **GitHub Actions**.
