Your search engine returned nothing. The document is right there. A cat has been
appointed head of relevance and is blaming the database. 🐱🔎

Build a small technical-help search engine with Apache Lucene and learn to check
the evidence: what was indexed, what became a candidate, how it ranked, and who
was allowed to see it. The cat supplies confidence. You supply tests.

## Start here 🐾

Start with [the inverted index](./01-foundations/01-inverted-index.mdx), then
[run the Java lab](./01-foundations/02-build-an-index.mdx). By the end you should
be able to explain a missing match, inspect a BM25 score, retrieve vector neighbors,
fuse ranked lists, and evaluate the result against a baseline.

**24 lessons · 7 modules · ~228 min of reading and guided practice**, plus a
**~5 min field guide** and the advanced setup reference. The capstone is a separate
extension project; first-time model downloads are additional.

## Prerequisites

Basic Java, collections, and a terminal. No machine-learning background required.
The runnable track targets **Java 21+ and Apache Lucene 10.3.1**, a deliberately
pinned teaching version, not a claim about the newest release. Browser exercises
work without Java. Lucene is a Java library, not a hosted search service; your
application owns ingestion, authorization, deployment, and the API around it.

## How to use the course

Each lesson includes a browser rehearsal, a concrete example, a bounded exercise,
an optional-depth fold, and a feedback quiz. The three-article postings illustration
and five-article Java corpus are named separately so their expected results are
not confused. The Java lab includes lexical, phrase, analyzer, vector, hybrid, and refresh
modes, and rebuilds its in-memory index on every run.

The foundational Java lab and ANN benchmark use explicitly synthetic coordinates.
Module 6 separately runs a real local embedding model and cross-encoder. The
operations lab uses disposable filesystem indexes and tests snapshot restoration.
No lab implements a production cluster or authorization service. Browser scoring
widgets isolate mechanisms; they are not Lucene running in JavaScript.

Lesson estimates use approximately 200 words per minute for prose, meme captions, and code,
rounded up, plus five minutes for the short rehearsal, quiz, and experiment
(eight minutes for initial lab setup). Optional folds are included in the word
counts; extended benchmark and service-design exercises may take longer.

## Version and sources

source depth, and optional technical detail fit your learning pace. Use that feedback
to choose which capstone extensions deserve a deeper follow-up module.
