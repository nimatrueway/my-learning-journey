# Deep Learning, No Snoozing 😼

You write software for a living. You've heard "neural networks" a thousand times. Time to actually get it.

**This course is built for you specifically:**

- 🕐 **Short lessons** — every lesson is 10–15 minutes. In, out, done.
- 🎮 **Play, don't read** — every lesson has something to drag, click, or break.
- 🐱 **Cats included** — most examples involve cats. This is non-negotiable.
- 🧮 **Light math** — intuition first. Equations only when they earn their place.
- 💻 **Real code** — small PyTorch scripts that run on your Mac.

## How each lesson works

1. **Hook** — a question that bugs you enough to keep reading
2. **Play** — an interactive widget; move sliders, watch things happen
3. **Tiny example** — a few lines of real code
4. **Recap** — 3 bullets, that's it
5. **Quiz** — one question; wrong answers get roasted
