## The hook

Time to assemble everything from lessons 1.1–1.4 into one complete, working network, and watch a number travel through it — every multiplication visible. This trip is called the **forward pass**, and it's the same trip whether the network has 4 neurons or 4 billion.

## Watch the number travel 🎢

Input → two hidden neurons (ReLU) → output. Drag the input and watch every node update:

<ForwardPassViz />

**Things to try:**

1. Slide x below **0.5** → neuron h₁ goes gray (asleep — its ReLU outputs 0). Only h₂ carries signal.
2. Slide x above **1.0** → now h₂ falls asleep instead. Different inputs wake different neurons. This is the network's whole trick: **different neurons handle different regions of the input**.
3. Around x = 0.75 → both awake, both contributing.

That "which neurons wake up" pattern *is* the computation. A cat photo wakes the pointy-ears neurons; a car photo wakes the wheel neurons.

## The tiny code version

The exact network above, in PyTorch:

```python
import torch
import torch.nn as nn

model = nn.Sequential(
    nn.Linear(1, 2),   # input → 2 hidden neurons
    nn.ReLU(),         # the drama
    nn.Linear(2, 1),   # hidden → output
)

x = torch.tensor([[1.0]])
y = model(x)           # ← THIS is the forward pass. One line.
```

When people say "run the model" or "inference" — this is all that's happening. Multiply, add, kink, repeat.

<details>
<summary>🤓 The actual math (optional — skip freely)</summary>

The whole widget as one expression:

$$y = \mathbf{v}^\top \, \text{relu}(\mathbf{w} x + \mathbf{b})$$

with $\mathbf{w} = [2, -1]$, $\mathbf{b} = [-1, 1]$, $\mathbf{v} = [1.5, 2]$. Expanded:

$$y = 1.5 \cdot \text{relu}(2x - 1) + 2 \cdot \text{relu}(-x + 1)$$

A deep network just nests this: $y = f_3(f_2(f_1(x)))$ where each $f_i$ is a layer. "Deep" literally means "more nesting."

</details>

## Recap 📌

- **Forward pass** = input flows through layers: multiply, add, activate, repeat
- Different inputs wake different neurons — that pattern is the computation
- `model(x)` in PyTorch runs the whole thing; GPT's forward pass is the same idea, much bigger
