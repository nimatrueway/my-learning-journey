# Module 8 — Encoder–Decoder Architectures 🔁

<Meme quote="Everything should be made as simple as possible, but no simpler." author="attributed to Albert Einstein — one context vector was, in fact, too simple" />

Modules 5 and 6 built a model that reads a sequence and continues it. But translation, transcription, and summarization are a different job: read **this** sequence, write a **different** one, possibly in another language, length, or alphabet. That job created the encoder–decoder — and, along the way, cross-attention, which is still the piece that connects Whisper's audio to its text and a translator's French to its English.

This module explains the split between reading and writing, the three attention flavors that appear once you have two towers, how to choose between encoder-only, decoder-only, and encoder–decoder models, and how the decoder's raw probabilities become actual sentences.
